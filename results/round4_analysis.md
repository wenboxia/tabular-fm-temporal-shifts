# 第四轮分析：短期占比 0.65 / 0.75 / 0.85（200 行，探索性；n_estimators=4）

按 results/phase56_prereg.md 末尾 "Exploratory short/long ratio analysis" 实现；不调用 TabPFN；**只描述，不检验，不设门槛**。数字单位：准确率为 %，差值为 pp。

**读法（请先读这一段）：**

1. 这是**探索性**分析，只描述，不检验。**做这个分析**是看过第三轮结果**之后**才决定的（起因：Electricity 在 200 行时的适应代价，以及阶段均衡的保留增益是否依赖第二、三轮沿用的 75/25 划分，即 KDD 论文调参网格的中间值）。0.65 / 0.85 是 KDD 论文网格里的另外两个值，不是看过数据后挑的；但 KDD 论文只在 600 / 800 / 1000 行的总记忆上搜过这个网格，200 行不在它的搜索范围内。
2. **不做多重比较校正，不设门槛**：表里的区间是各自独立的 95% t 区间（每个 (数据集, 占比, 指标) 一个），数量很多，偶然的"全部为正"或"区间不含 0"不能当作证据；第三轮的结论（Holm 家族的 8 个检验）不被本分析改变。
3. 10 个 seed 不是 10 个独立的流：seed 只改变留出集的抽样和 TabPFN 的随机性，流（去掉各自的留出行之后）在 seed 之间大部分相同，阶段均衡长期池里选到的行也几乎相同，所以"正号 seed 数"主要反映留出集抽样噪声，区间偏窄。
4. 只在 **200 行**上做；相对 KDD 的 ADAPT 差（Electricity）：1000 行 −0.51 pp，200 行 −2.10 pp，两者都没过 −0.5 pp 的非劣性边界；本分析不能推到 1000 行。
5. 0.75 列是第三轮的 `dual200` / `dual200_rb`（commit 不同于第四轮）。`calib4` 只在 electricity / dual200_rb / seed 0 这**一个**运行上逐位复现了第三轮（本脚本读 calib4 的 npz 再核对一次，见下面的"calib4 核对"）；其余运行不能由它推出，靠本脚本逐 seed 核对 y / hold_idx / stream_idx / boundaries / zone / mem_boundaries 相同，以及标签重放的 digest。

载入 280 个运行：第四轮 160 个，第三轮 110 个，第二轮 10 个。
